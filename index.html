Reviewer Wizard

Model QAClash detectionC#WPFRevit API

A step-by-step QA review of the whole Revit model in one window. Each discipline has its own tab of checks, each check lists the elements that fail it, and one click shows any of them in 3D.

  • Tabs for walls, floors, roofs, structure, doors & windows, ceilings, interior, exterior
  • Clash detection with a section-box 3D view per clash
  • Wall checks: location line, height, type, sill plate
  • Review progress tracked across all checks

src/Modelling/RoofCreator.cs

Roof Creator

Multiple plate heightsRidge cap · FasciaExternalEventMVVM

Pick one seed wall and the tool traces the connected walls, clusters them, and draws a live roof-plan preview. Set slope, overhang and hip or gable for each edge, then build the footprint roof and finish it with ridge caps and fascia.

  • Trace seed wall or select multiple walls
  • Per-edge table: defines slope, slope, overhang, hip or gable
  • Floating WPF palette driven by ExternalEvent
  • Roof Tools: ridge cap and fascia with soffits
FootprintBuilder.cssketch
var roof = doc.Create.NewFootPrintRoof(
    footprint, level, roofType, out var map);

foreach (ModelCurve edge in map)
{
    var cfg = edges[edge.Id];
    roof.set_DefinesSlope(edge, cfg.DefinesSlope);
    roof.set_SlopeAngle(edge, cfg.Slope);
    roof.set_Overhang(edge, cfg.Overhang);
}
src/Concepts/ModelChecker.cs · concept

Model Checker

Code complianceEBC 201Rule engine

The next step after Reviewer Wizard: checks driven by building-code rule sets. Choose a country and code, such as the Egyptian Building Code, and each rule is tested against the model with the required and actual value side by side.

  • Rule sets by code, discipline and building type
  • Required vs actual value for every failing element
  • Project-specific rules layered on top of the code

Kitchen Creator

Cabinet layoutWall elevationWPF Canvas

Select the walls of a kitchen and place cabinet families along their faces. A canvas-first editor shows the wall in plan or elevation, splits it into segments, and lets you drop a family and type into each one with live dimensions.

  • Segment editor: split, merge, lock, drag dividers
  • Plan / elevation preview of the selected wall
  • Family palette with types and parameters
models/HotelInteriors.rvt · A1 drawing set

Revit Drawing Set

Architectural modellingInterior documentationRevit families

A 12-sheet A1 set for hotel corridors and guest rooms, all set up and exported from Revit 2024. It covers general arrangement plans, ceilings and lighting, interior and bathroom elevations, construction details and the loadable families used in the model. Views are laid out on a consistent grid and set to working scales from 1:5 to 1:100.
